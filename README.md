# ☕ Coffee Break - Landing Page

Una página web moderna y adaptable para una cafetería de especialidad ficticia, desarrollada como primer proyecto de maquetación web.

🔗 **[Ver Demo en vivo](https://netlify.app/)**

## ✨ Características (optativo)

- 📱 **Diseño 100% Responsive:** Adaptado para teléfonos, tablets y computadoras de escritorio mediante el sistema de grillas de Bootstrap.
- 🧭 **Barra de navegación interactiva:** Navbar colapsable con enlaces a secciones de la página.
- 🖼️ **Carrusel de imágenes:** Muestra de productos destacados utilizando componentes de Bootstrap.
- 📋 **Formulario de contacto:** Maquetado con validaciones visuales de interfaz.
- 🎨 **Estilos personalizados:** Hoja de estilos externa para tipografías, variables de color y espaciados propios.

## 🚀 Cómo ver el proyecto localmente

1. Clona este repositorio o descarga el archivo ZIP:

   ```
   git clone https://github.com/rollingcodeschool/ejemplo-readme
   ```

2. Entra en la carpeta del proyecto:

    ```
    cd ejemplo-readme
    ```

1. Abre el archivo index.html en tu navegador web de preferencia (o usa la extensión Live Server en Visual Studio Code).
